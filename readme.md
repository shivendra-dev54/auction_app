# Auction app

A basic app for hosting auctions. This app provide platform to host auctions for the items we have, we can add item info onto the app and host auction for it. Other users can participate and bid for that item, the bidding system is built with websocket to provide near real-time experience.

## Techstack
**Backend:**
- Bun
- Express.js
- drizzle

**Database:**
- postgres by supabase
